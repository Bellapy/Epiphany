### 📖 Sobre o Jogo

**EPIPHANY** é um jogo de aventura 2D com foco em narrativa e exploração. Você assume o papel de uma viajante sem memórias que desperta em Zelfin, um mundo habitado por espíritos que representam a própria natureza. Guiada pela guardiã Ayla, você embarca em uma jornada para desvendar os mistérios da sua chegada e o impacto sutil que sua presença causa na harmonia deste lugar encantado.

O jogo explora temas de conexão, memória e o efeito borboleta de nossas ações, tudo envolto em uma atmosfera de pixel art cativante e uma trilha sonora imersiva.

### ✨ Recursos Principais

*   **Narrativa Conduzida pela Exploração:** Descubra a história de Zelfin e da sua personagem interagindo com o mundo e seus habitantes.
*   **Personagens Cativantes:** Conheça Ayla, a sábia guardiã, Zric, o excêntrico inventor, e outros espíritos que povoam este universo.
*   **Puzzles Ambientais:** Resolva quebra-cabeças integrados ao cenário para progredir na sua jornada.
*   **Sistema de Diálogo e Reflexão:** Mergulhe nos pensamentos da personagem e nas conversas que moldam sua compreensão do mundo.
*   **Direção de Arte em Pixel Art:** Um estilo visual nostálgico e detalhado que dá vida ao mundo mágico de Zelfin.
*   **Trilha Sonora Original:** Músicas compostas para criar uma atmosfera de mistério, maravilha e melancolia.

### 🚀 Como Jogar (Localmente)

Esta seção é para desenvolvedores que desejam executar o projeto a partir do editor da Unity.

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/Bellapy/Epiphany
    ```
2.  **Abra no Unity:** Abra o projeto com o Unity Hub, utilizando a versão **2022.3.x LTS** ou superior.
3.  **Execute o jogo:**
    *   Navegue até a pasta `Assets/Scenes/`.
    *   Abra a cena `Menu`.
    *   Pressione o botão **Play** no editor.

#### Controles

| Tecla(s) | Ação |
| :--- | :--- |
| **W, A, S, D** | Mover a personagem |
| **E** | Interagir com objetos e personagens |
| **F** | Abrir/Fechar Menu de Pausa/Opções |
| **Espaço / Enter** | Avançar diálogos |
